# v1.4.5 brief

**Requested:** a screenshot with red arrows showing the gap above "02 Our range"/the heading (section-top to text) is clearly bigger than the gap below it (text to the product card). "Fix this margin issue. It should have equal space above and below." Also: explicitly reminded to keep the Products section fitting a single screen (the v1.4.2 work), since this change touches the same spacing.

**Root cause:** the gap above came from two stacked sources — `.products`'s own `padding-top` (up to 2.5rem) *plus* `.products-heading`'s own top padding (.25rem) — while the gap below came from only `.products-heading`'s bottom padding (1.1rem). Different sources, different values, visibly unequal.

**Delivered:**
- Removed `.products-heading`'s own top/bottom padding entirely. The gap above now comes solely from `.products`'s `padding-top`; the gap below now comes from `.products-heading`'s `margin-bottom`, set to the *exact same* `clamp()` expression — so they're identical by construction at any viewport width, not just tuned to look close.
- This alone added back some of the height v1.4.2 had trimmed (the old unequal gaps summed to less than two equal ones do), so re-checked the fit and trimmed the shared clamp's ceiling (2.5rem → 2rem) and `.product-pagination`'s top margin (1.3rem → 1rem) to compensate.

**Verified:** gap above/below measured as pixel-identical (32px/32px) at both 1440×816 and 1366×768; the section still fits fully inside the viewport at both, with 32-53px to spare — a real margin, not a hair's-breadth fit. No horizontal overflow on mobile, no console errors.

**Released as:** v1.4.5 (patch — spacing correction to an existing section, per `VERSIONING.md`).
