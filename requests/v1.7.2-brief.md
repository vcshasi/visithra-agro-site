# v1.7.2 brief

**Requested:** "Document the steps in case of a manual deployment to a document with name 'Manual Deployment Procedure' including steps to build, how to build artifact, deploy the artifact into cloudfare (without .gitignore - document that incident also so that it would not be repeated). Once done Summarize the deployment step by step what has be done so far."

**Delivered:** `DEPLOYMENT.md`, titled "Manual Deployment Procedure", covering:
1. One-time machine setup (installing Node.js, `wrangler login`, confirming authentication).
2. What "building the artifact" means for this project specifically — there is no build step (no framework, bundler, or compiler), so this section is a readiness checklist instead (version bumped, `CONFIG` values live, `.assetsignore`/`_headers` present and current) rather than a build command.
3. The actual deploy command (`npx wrangler deploy`) and the one-time-per-project `wrangler pages project create` step.
4. A dedicated, explicit section on the `.gitignore` incident: what happened (the first deploy publicly uploaded `.git/*` and `.claude/*` despite both being gitignored), the root cause (Wrangler's asset upload never reads `.gitignore` — only a separate `.assetsignore` file, which must be maintained by hand and kept in sync), the exact fix, and the standing rule going forward (anything added to `.gitignore` for a reason that also matters for what gets deployed must also be added to `.assetsignore`, as a second, deliberate edit — one does not imply the other).
5. A mandatory post-deploy verification checklist (curl checks that the real site loads, that `.git`/docs are NOT reachable, and that security headers are actually present on live responses — not just assumed from config) — directly derived from how the incident was actually caught and fixed, so the same verification habit carries forward instead of being a one-off reaction.
6. Rollback commands/process and a quick-reference table of what each deployment-related file does.

Linked from `README.md`'s hosting section.
