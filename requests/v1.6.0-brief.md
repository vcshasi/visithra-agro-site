# v1.6.0 brief

**Requested:**
1. Add "Home" to the header nav, hyperlinked to the site's landing page (the first section of the page).
2. Make the "Visithra Agro" logo and its font size a bit bigger — looked too small compared to other page elements.
3. For the "Products" header link: show Gloriosa Superba and Coconut Products as subitems, plus a "more products yet to come" note; clicking a subitem should navigate to the corresponding product carousel card.
4. Product section: auto-scroll through a product family's images; once a family's images are exhausted, advance to the next family and scroll its images, looping back to the first family after the last, continuing indefinitely. Start automatically once the visitor reaches the Products section; stop permanently when the visitor interrupts/clicks.

**Delivered:**
1. `<a href="#home">Home</a>` added as the first item in `.site-menu`, ahead of "Our story" — `#home` is the hero section's existing id.
2. `.brand-mark` (the circular "V" mark) grew 27px → 34px with its glyph scaled to match; `.brand`'s "VISITHRA" text grew `.8rem` → `.96rem`; the smaller "AGRO" sub-label grew `.51rem` → `.58rem`. Applies to both the header and footer since they share the `.brand` markup/class. Verified the header still fits everything at 76px tall with no overflow.
3. "Products" is now a `.nav-item.has-submenu` wrapping a `.submenu` dropdown (`Gloriosa Superba`, `Coconut Products`, and a muted non-clickable "More products yet to come" line), shown on `:hover`/`:focus-within` on desktop, always expanded (indented, static) on mobile. Each family link carries `data-family-link="gloriosa"`/`"coconut"`; a click handler in `script.js` finds the matching `.product-card` (now tagged `data-family="gloriosa"`/`"coconut"`) and scrolls both the page (to the top of `#products`) and the family carousel (to that card) — reusing the same `scrollIntoView` approach the existing prev/next carousel buttons already use.
4. Added a self-contained autoplay module to `script.js`: every 3.5s, advance the current family's gallery by one photo; once a family's last photo is reached, advance to the next family's card and reset its gallery to photo 1, wrapping back to the first family after the last. Starts via `IntersectionObserver` on `#products` (threshold 0.4) and pauses (not permanently) whenever the section scrolls out of view; stops permanently — flag never resets — the instant the visitor clicks a carousel-button or gallery-nav button, or does a pointerdown/keydown on the family track or a gallery strip (covers manual drag-scrolling and arrow-key use). Also skipped from the start for `prefers-reduced-motion: reduce`.

**Bug found and fixed along the way:** while testing the enlarged mobile menu, discovered that `.site-header`'s `backdrop-filter` (added in v1.5.5) makes the header the *containing block* for its `position: fixed` `.site-menu` child per spec — so the fullscreen mobile nav overlay was being sized against the header's own ~64px box instead of the viewport, severely clipping it. This bug predates today's work but had gone unnoticed. Fixed by dropping `backdrop-filter` on `.site-header` specifically inside the `max-width: 760px` breakpoint.

**Verified:**
- Desktop (1280–1366px wide): header shows all four nav items with no wrap/overflow; hovering "Products" reveals the dropdown positioned cleanly below it with no clipping; confirmed via computed style (`opacity`, `visibility`, bounding rect) since this test browser's synthetic `:hover` state doesn't always survive across separate tool calls — batching hover + read in one step showed the transition completing correctly (opacity 0 → 1, `visibility: visible`).
- Family-link click: directly verified (with the test harness's smooth-scroll substituted for instant, per this session's established workaround for that specific limitation) that clicking "Coconut Products" resolves the correct card index, scrolls the page to `#products`, and scrolls the family track so the Coconut card's left edge aligns with the track's edge.
- Autoplay state machine: verified by calling the internal step function directly ten times in sequence — correctly advances gloriosa through all 5 photos, switches to coconut and resets it to photo 1, advances coconut through all 3 photos, then wraps back to gloriosa at photo 1, repeating. Verified all five interrupt paths (family carousel-button, gallery-nav button, track pointerdown, gallery pointerdown, track keydown) each set the permanent-stop flag and clear the running timer.
- Mobile (375×812): after the backdrop-filter fix, the fullscreen nav now correctly fills the entire 812px viewport (previously ~128px, clipped) and all seven menu rows (Home, Our story, Products, Gloriosa Superba, Coconut Products, the note, Contact) fit without needing the newly-added `overflow-y: auto` safety net, confirmed visually via screenshot.
- Re-confirmed the Products section's existing "fits one screen" sizing (from v1.5.6) is unaffected: still ~33px of margin below the card at 1280×700, no horizontal overflow anywhere tested.

**Released as:** v1.6.0 (minor — the Products dropdown navigation and the autoplay carousel are new features, per `VERSIONING.md`).
