**Requested:**
1. Apply the same fixed 4:3 framed-box treatment used on the product galleries to the hero illustration (the image above the About Us section) as well. Product gallery frame sizing itself can be revisited later.
2. Remove per-sub-product image references entirely. Only the main product group (Gloriosa Superba Products / Coconut Products) should show images, as a horizontal-scroll gallery like today. - Sub-product buttons were replaced with a plain `<ul>` list of sub-product name + description text — no `data-gallery-*` wiring, no click handlers, no arrow icon.
- Removed the now-inaccurate "Select a sub-product to view its available photos." hint text.

**Released as:** v1.1.0 (minor — behavioural/structural change to an existing feature, per `VERSIONING.md`).
