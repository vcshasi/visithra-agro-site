# v1.5.8 brief

**Requested:** "Highlight the family-switcher prev/next buttons with some other colour or a glow effect to distinguish from background colour. Fix it."

**Delivered:**
`.carousel-button`'s resting state changed from a near-invisible `border: 1px solid rgba(255,255,255,.3)` / `background: rgba(15,61,43,.55)` (a dark green almost identical to the section's own background) to a rust-tinted treatment using the site's existing accent colour (`--rust: #d95c31`, already used for "02" in the section label and other highlights):
- `border: 1px solid rgba(217,92,49,.65)`, `background: rgba(217,92,49,.2)`
- `box-shadow: 0 0 0 1px rgba(217,92,49,.1), 0 0 16px -1px rgba(217,92,49,.65)` for a soft glow around the ring

The hover/focus state (previously a plain lime swap) now also carries a matching lime-coloured glow, so the highlight stays consistent between resting and interactive states. Button size (34px desktop / 38px mobile, from v1.5.7) and the "01 / 02" page-number label are unchanged — this is a colour/shadow-only change.

**Verified:** confirmed via computed styles (`border`, `backgroundColor`, `boxShadow`) that the new values are applied and the button's box size is unchanged (34×34px), and visually via screenshot at 1280×800 — the rust glow is clearly visible against the dark green Products background, a large contrast improvement over the previous near-invisible state.

**Released as:** v1.5.8 (patch — a visual/colour refinement to an existing element, per `VERSIONING.md`).
